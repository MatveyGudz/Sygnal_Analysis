# Sygnal_Analysis
Консольное приложение на C++ для численного моделирования и анализа входного и выходного сигналов.  Проект реализует формирование временной сетки, расчёт входного сигнала, преобразование сигнала через заданную нелинейную характеристику, вычисление длительности импульса и оценку погрешности численного расчёта.

Возможности
формирование временной сетки;
расчёт входного сигнала Uin(t);
расчёт выходного сигнала Uout(Uin);
вычисление длительности импульса;
вывод результатов в консольную таблицу;
сохранение результатов в .txt;
оценка погрешности расчётов при увеличении количества точек;
работа с динамически выделяемой памятью;
консольное меню для управления расчётами.

Основные изучаемые темы:
работа с массивами;
указатели и динамическая память;
функции;
циклы и условные конструкции;
математические вычисления;
работа с файлами;
оценка численной погрешности.
